# An Easy (EZ) WordPress ActivityPub plugin 3td party API thing

This is a pet project to create a static class for the most basic ActivityPub 
third-party uses.

The purpose of this project is to create an all in one easy API for things to
do with the WordPress ActivtyPub plugin.

My intention is to make a simple library and a working tutorial for some simple 
uses of the ActivityPub plugin.

## Please submit code snippets

I would love to include your snippets if you are prepared to share under the MIT
license for working with ActivityPub.

## Why the MIT license

My hope is that this project matures to the point that the team running the main
ActivityPub plugin want to adopt it. The plugin is MIT, so this set of simple or
fairly simple aliases and snippets is also MIT for ease of working together.

## Other end goals

If the lovely folk maintaining the plugin don't feel this is a good fit, perhaps
it might be an idea to make this a plugin with the ActivityPub plugin a must use
so that other third party devs can make this must use and rely on the simplified
API that this class will be.

Another idea might be to make it a library that can be included.

I'm sure there are other ideas down the road.
